# Shezan Mahmud — Portfolio Website

A modern, responsive portfolio website built with vanilla HTML, CSS, and JavaScript. Features a dark/light theme, smooth animations, scroll-reveal effects, and a fully accessible, performant codebase.

## ✨ Features

- **Dark/Light Mode** — Persisted in localStorage, respects system preference
- **Responsive Design** — Mobile-first, works beautifully on all screen sizes
- **Scroll Animations** — IntersectionObserver-powered reveal animations
- **Micro-interactions** — Hover states, focus styles, loading feedback
- **Accessible** — Semantic HTML, ARIA labels, keyboard navigation, WCAG AA contrast
- **Performance** — No build step, no dependencies (except Lucide icons via CDN)
- **Contact Form** — Client-side validation with toast notifications
- **Animated Hero** — Rotating roles, typing code animation, floating tech cards
